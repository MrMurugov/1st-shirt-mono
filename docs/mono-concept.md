# Mono Concept: дизайн и перенос в WordPress

Этот репозиторий — отдельный визуальный вариант того же сайта. Маршруты,
контентные данные, фотографии, общие компоненты и JavaScript-сценарии сохранены,
поэтому концепт не требует отдельной модели данных в WordPress.

## Визуальная система

- интерфейсная палитра ограничена тёплым графитом, молочным и серо-бежевыми
  оттенками;
- фотографии товаров и производства остаются цветными, чтобы не искажать
  реальный цвет ткани и нанесения;
- крупные заголовки используют локальный Cormorant Garamond, интерфейс и
  основной текст — локальный Manrope;
- радиусы собраны в четыре уровня: `14px`, `26px`, `38px` и pill-форма;
- цвета, тени, шрифты, контейнеры и радиусы определены CSS-переменными в
  `:root` файла `src/assets/css/styles-v2.css`.

## Что переносится без изменения

- разметка общих компонентов из `src/_includes/components`;
- структура страниц и товарных шаблонов;
- данные из `src/_data`;
- квадратная товарная галерея и набор из пяти изображений;
- каталог с фильтрами, меню, accordion, таблицы с горизонтальным скроллом,
  форма и modal;
- локальные шрифты и изображения.

JavaScript написан без зависимости от Eleventy. При переносе его можно
подключить в WordPress через `wp_enqueue_script`, сохранив существующие
`data-*`-атрибуты.

## Что относится только к GitHub Pages

- `pathPrefix` в `eleventy.config.mjs`;
- `baseUrl` в `src/_data/site.json`;
- `pagesPrefix` в скриптах сборки;
- workflow `.github/workflows/pages.yml`.

Эти значения не входят в визуальные компоненты. В WordPress URL формируются
функциями темы, поэтому префикс `/1st-shirt-mono/` переносить не нужно.

## Рекомендуемая реализация в теме

1. Подключить локальные шрифты и CSS через `wp_enqueue_style`.
2. Перенести `:root` как слой design tokens темы.
3. Сопоставить Nunjucks-компоненты с template parts или динамическими блоками.
4. Сохранить имена классов и `data-*`-атрибуты интерактивных элементов.
5. Подключить данные товаров, категорий, решений и кейсов по карте из
   `wordpress-mapping.md`.

Так дизайн можно перенести пиксельно близко без изменения согласованной
структуры сайта.
