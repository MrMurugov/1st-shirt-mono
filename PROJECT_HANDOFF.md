# Передача проекта `1st-shirt`

Дата миграции: 2026-07-23 (UTC)

## Назначение

Этот файл сохраняет активный migration-turn исходного чата. `codex fork`
гарантированно переносит завершённую историю, но активный turn может оказаться
в fork только частично. Поэтому полный запрос и результат миграции записаны
здесь отдельно.

После открытия fork продолжать работу следует в каталоге:

`/root/projects/1st-shirt`

## Запрос пользователя на миграцию

> Создай из текущей сессии локальный Codex-проект `1st-shirt` в
> `/root/projects/1st-shirt`.
>
> Безопасно скопируй туда всю текущую рабочую папку вместе с Git и скрытыми
> файлами, проверь целостность и оставь источник нетронутым. Создай fork
> текущего чата с завершённой историей, привяжи его к новому проекту и сохрани
> текущий migration-turn в PROJECT_HANDOFF.md.
>
> Не редактируй внутренние файлы сессий Codex вручную, не перезаписывай
> существующий каталог и ничего не удаляй. В конце проверь Git, cwd нового
> thread и сообщи, как его открыть.

## Контекст проекта

- Проект: B2B-сайт печати на футболках и другой одежде.
- Первый этап: самостоятельный frontend с тестовыми товарами и данными для
  публикации на GitHub Pages.
- Следующий этап: перенос frontend в WordPress; структура и компоненты должны
  оставаться совместимыми с такой интеграцией.
- Клиенту понравилось общее направление референса Floreo, но буквальное
  повторение шаблона, зелёная палитра и прописные шрифты были отклонены.
- Желаемое направление: более самостоятельная, выразительная стилистика,
  ориентированная на лидеров рынка.
- Репозиторий: `https://github.com/MrMurugov/1st-shirt.git`.
